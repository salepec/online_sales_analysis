# Online Sales Analysis

## Project Description

This project is a simple Python application for managing products and simulating a shopping cart.

The application allows users to:
- Create and manage products.
- Add products to inventory.
- Remove products from inventory.
- Display available products.
- Calculate total inventory value.
- Randomly select products and add them to a shopping cart.
- Calculate the total shopping cart price.

## Project Structure

- `product.py` - Contains the Product class.
- `product_manager.py` - Contains the ProductManager class.
- `cart.py` - Contains the Cart class.
- `main.py` - Main application file.
- `.gitignore` - Specifies files ignored by Git.

## Classes

### Product
Represents an individual product with a name, price, and quantity.

### ProductManager
Manages the product inventory. It supports adding, removing, displaying products, and calculating total inventory value.

### Cart
Manages shopping cart items, displays selected products, and calculates the total price.

## How to Run

Make sure Python is installed.

Run the application using:

```bash
python main.py
```
